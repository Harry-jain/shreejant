# Shreejan AI Solutions

**Engineering Intelligence. Building Tomorrow.**

Premium business website and autonomous AI systems engine for **SHREEJAN AI SOLUTIONS** — Mumbai-based Gen AI and digital systems agency.

## Stack
- Latest version Next JS (App Router)
- TypeScript 5.7
- Tailwind CSS v4
- Framer Motion 12
- Three.js
- Resend
- MDX

## Getting Started
```bash
pnpm install
pnpm dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

## Production Build
```bash
pnpm build
pnpm start
```
